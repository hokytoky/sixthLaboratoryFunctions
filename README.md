## Цель
Научиться выделять повторяющееся вычисление в функцию с понятными параметрами и результатом, передавать массив вместе с его размером и повторно использовать одну функцию для разных данных.

## Описание
Программа читает два массива P и Q произвольных размеров k и m и находит сумму ненулевых элементов каждого из них. Расчёт выполняет одна функция sumNonZero, которая вызывается дважды. Ввод и вывод находятся в main. При неверных данных программа выводит INVALID.

## Исходные данные
- k: размер массива P, целое от 1 до 100
- k вещественных чисел массива P, каждое по модулю не больше 1000
- m: размер массива Q, целое от 1 до 100
- m вещественных чисел массива Q, каждое по модулю не больше 1000
- Пример: `4`, затем `1 0 -2.5 4`, затем `3`, затем `0 0 3`

## Ожидаемые результаты
Программа выводит две строки: сумму ненулевых элементов массива P и сумму ненулевых элементов массива Q.
- Для примера выше: 2.5 и 3
- Если все элементы массива нулевые, сумма равна 0
